# AssetIQ website

```
index.html        page structure (HTML only)
css/styles.css    all styles, animations and hero-scene styling
js/main.js        original page logic (nav, calculator, forms, FAQ)
js/effects.js     scroll reveal and page effects
js/hero-rig.js    GSAP-driven doctor animation (walk, scan, thumbs-up, eyes)
js/hero-react.js  React components that mount the hero scene
```
Libraries (React 18.3.1, GSAP 3.12.5) load from cdnjs, pinned.
Open `index.html` in a browser; no build step is needed. a
